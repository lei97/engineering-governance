**失败时能确定什么**

- 如果发现影响行为的必要前提没有写明，可以确定该描述未满足前提显式化要求。如果只能观察到双方对某处解释不同，可以确定该处理解存在分歧。依据是 REQ-100 对必要前提和复述对照的要求。
- 如果知道双方有分歧，却无法通过对照指出差异所在，可以确定本次对照未达到定位要求。若 YAML 和来源材料都没有回答争议中的行为问题，分歧本身不足以确定哪种解释应当成为已确认的要求。REQ-100 要求作者核对 Agent 的复述，SRC-100 只说明这一做法的目的。
