# E001：真源识别与人类可理解性（实验协议）

## 目的

检验增加结构化 YAML 记录是否比 Markdown 需求文档/普通仓库检索更有效，不预设 YAML 获胜。

## 三个条件

- A：只提供同义 Markdown 文档。
- B：提供 v0.1 YAML 记录及校验器。
- C：只提供代码与零散注释（探索现状，不作规范基线）。

各组获得相同任务：找出一个需求与实现冲突、说明谁拥有解释权、提出最小修复方案。所有条件均应拥有可定位的相同事实内容；不要给 B 组额外透露答案。任务顺序随机化并记录模型和版本。

## 数据收集

- 人阅读后是否能准确解释关键字段和真实需求（盲测）；
- Agent 对事实、推断与冲突的识别是否正确；
- 引用正确率、错误修改率、查找耗时、上下文 token（能测则记录）；
- 增加/维护结构化记录的人力成本。

## 判定边界

样本少时只报告个案，不宣称统计显著；同一任务不同模型应分别记录。语义正确性须由人参照原始需求人工评估。
