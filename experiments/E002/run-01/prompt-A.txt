id: REQ-201
kind: requirement
title: 取消探索对正式作品正文的约束
status: proposed
origin: SRC-201
statement: |
  本条仅用于 E002 合成案例。对报告成功的同一取消请求，两项写入约束从系统开始处理该请求起适用，到该请求报告成功前为止。
  探索与取消处理期间均允许独立且合法的其他编辑修改同一正式作品。直接写入归属于实际执行写入的操作。取消触发的下游正文变化计入该取消的因果影响。
  取同一正式作品在探索开始前、取消处理开始前和报告成功后的正文值。分别把报告成功后的正文与前两个参照点的正文比较，结果作为观察记录。版本号、时间戳等其他属性在比较范围之外。
  超时后的回滚和重试，以及报告成功后的延迟写入，均未规定。
acceptance:
  - 在约束区间内，取消操作不得直接写入正式作品正文，包括写入同一正文值。
  - 在约束区间内，取消操作不得直接或间接造成正式作品正文变化，包括随后被恢复的变化。
</业务要求>

<共同证据和轨迹>
先确定需求是否对本题行为给出适用约束，再用轨迹判断该约束是否满足。没有适用约束时即可记录未规定。有适用约束时，再判断证据是否充分。

| 结果 | 判定依据 |
| --- | --- |
| 满足 | 适用约束明确，证据足以证明本次行为符合该约束。 |
| 违反 | 适用约束明确，证据足以证明本次行为违反该约束。 |
| 未规定 | 需求对题目所问的行为没有给出适用约束。 |
| 证据不足 | 已有适用约束，但给出的轨迹无法确定本次行为是否符合。 |

| 判断 | 足以支持的证据 |
| --- | --- |
| 两个参照点的正文相等或不同 | 两个参照都能定位到同一正式作品、各自的边界事件及对应的正文值。 |
| 直接禁写约束满足 | 轨迹明确覆盖目标正文在区间内的全部直接写入路径，包含同值写入和随后恢复的写入。记录完整，写入的操作归属与先后可核对，且未发现归属本次取消的直接写入。 |
| 直接禁写约束违反 | 至少有一条发生在区间内、归属本次取消且写入目标正文的直接写入证据。该次证据可复核即可确认违反。 |
| 因果约束满足 | 轨迹完整覆盖区间内所有正文变化，含下游路径和后来恢复的变化，并能排除其中任何变化由本次取消引起。 |
| 因果约束违反 | 至少有一次发生在区间内的正文变化，有直接写入证据或可复核的触发链将变化归因于本次取消。共享标识和相邻时间可用于查找关联事件，归因还需要触发与结果对应的证据。 |

用缺少某类事件来支持“满足”时，先核对记录的覆盖范围、采集完整性与操作归属。若边界事件与写入的先后、路径覆盖或归属缺失，且没有足以判定违反的证据，该项记为证据不足。完整记录只支持对所声明的作品属性、时间区间和写入路径作缺失判断。范围以外的副作用仍需相应证据。两组收到相同的覆盖声明和轨迹。

对 T1 至 T6，先判断成功完成时的正文是否分别与探索开始前、取消开始前相同，再分别判定直接写入约束与因果约束。T7 判定超时后的回滚和重试要求。每个判定需指出适用规则和轨迹证据，再汇总本题结果。

任一已明确的适用约束违反，汇总记为违反。其余情况下，只要有适用约束证据不足，汇总记为证据不足。已有明确约束且全部满足时记为满足。题目所问行为没有适用约束时记为未规定。汇总时保留各列判断及其理由。

甲、乙表示两个不同的正文值。T1 至 T5 明确提供完整区间记录，覆盖目标正文的全部直接和下游写入路径，包括同值写入及最后被恢复的变化。操作归属、因果链、正文取样及事件先后皆可核对。T6 仅有正文取样值，缺少上述区间证据。T7 单独询问超时规则。

| 轨迹 | 探索开始前 → 取消开始前 → 成功完成后 | 已知行为或证据 |
| --- | --- | --- |
| T1 · 取消前合法编辑 | 甲 → 乙 → 乙 | 另一操作在取消开始前写入乙。完整的取消区间记录中无正文写入条目。 |
| T2 · 取消中合法编辑 | 甲 → 甲 → 乙 | 取消期间，独立且合法的另一操作把正文改为乙。可确认该编辑与取消无因果关系。 |
| T3 · 取消写入后恢复 | 甲 → 甲 → 甲 | 取消直接写入乙，随后再写回甲。 |
| T4 · 取消写入同值 | 甲 → 甲 → 甲 | 记录证实取消完成了一次写入，正文仍为甲，期间也无其他正文变化。 |
| T5 · 取消触发间接变化 | 甲 → 甲 → 乙 | 取消发送更新请求。同一请求的关联记录表明，下游操作响应请求并在取消期间写入乙。取消自身没有直接写入。 |
| T6 · 同值但缺少归属 | 甲 → 甲 → 甲 | 只保存三个取样点。区间事件记录和写入归属缺失。 |
| T7 · 超时 | 甲 → 甲 → 无成功完成事件 | 取消开始后发生超时。判断材料是否规定此时必须回滚或重试。 |
