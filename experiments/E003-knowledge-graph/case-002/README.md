## 验收边界

在扫描目录及其子目录时，逐文件报告小写 `.yml` 不受支持并提示使用 `.yaml`。混放和仅有 `.yml` 的批次都返回失败并指出相应路径。`.yml` 不计入 `.yaml` 记录数，也不参与 ID 索引。保留其余 `.yaml` 的验证和诊断，纯 `.yaml` 批次沿用现有行为。大小写变体、其他扩展名和输出格式调整留在本例范围之外。

留出验收在派发前校准。用多层目录和多个 `.yml` 检查逐文件报告，用仍含普通 `.yaml` 错误的混放批次检测是否过早返回，用改名后的来源检查索引边界。用合法批次与现有测试检查回归。以退出码、触发文件和目标诊断验收，允许无关诊断随合理输入变化。临时参考实现通过留出验收，原版以及漏报嵌套文件、提前返回、错误入索引、漏改名提示和误报目录的实现均未通过。 [留出验收](check.py) · [校准记录](calibration.json)
