## 金标

每批逐版本区分是否正常走完整批、未捕获异常、摘要、按文件定位的诊断以及独立检查是否执行、跳过或未到达。全部退出码为 1。旧版批次 2、6 已收集 Schema 错误，但异常后没有对外发布诊断，也未执行后续文件的来源检查。旧版批次 3 则在首条记录的 `kind` 分支中断，后续文件连 Schema 检查都未到达。

开放题单列历史真实性、目标版本适用性和跨版本推断。旧版非空列表的历史观察有效，其新版迁移预期失效。关于旧版任意列表的全称主张，与同一版本的空列表证据冲突。按结论、条件和证据逐项评阅，修订提议单列为候选，由作者另行确认。

## 材料等义与隔离

A、B、C 共用交接任务、历史原文摘录、原始 CLI 证据及两个版本的源码、Schema、规范和测试。B 加线性摘要 673 字符，C 加文本关系图 879 字符。独立评阅分别从两种呈现恢复六条主张，逐项核对方向、否定、版本、条件、状态与证据。K1 初稿的“报告”可被读成 CLI 输出，最终两种呈现均明确为“收集”。历史索引按字符串 ID 保留各自的首条记录。 [共同任务](task.md) · [主张清单](history-claims.json) · [摘要](summary.md) · [关系图](graph.md) · [独立材料审计](material-audit.md)

分发采用显式文件清单。三包共同文件的哈希一致，B、C 分别只多出各自的一个文件。金标、评分说明、评阅和试答记录在组织者侧。审计在分发材料内未发现金标或针对题目的新版结论回填。共同提供的原始诊断和回归测试本身含有解题证据。会话隔离依赖独立目录和访问约定。

## 独立试答

一个独立 A 组会话只收到共同材料。试答答对五项主判断，并正确区分 14 条运行的完成状态、异常、摘要和对外诊断。第一题在给定输入上的判断正确，若将范围扩展到一般规则，还可明确加上「来源 ID 与记录自身不同」的条件。试答把修订标为待维护者确认。 [原始试答](pilot-response.md)

这一份试答显示本案在共同材料下已有明显的上限风险，适合校准评分。其结果不计入正式对照样本。正式案例应加入另一种真实失效机制，再冻结含该案例的完整批次。对照结论的范围是线性摘要与文本关系表示，净工时及图检索效用仍缺少实测。

## 复核与冻结

使用 Python 3.12.15、PyYAML 6.0.4 和 jsonschema 4.26.0。从本文件所在目录执行以下命令，可重放金标并生成任一组的隔离目录。`--destination` 应指向新目录。 [冻结清单与候选分发顺序](freeze.json)

```sh
python -B prepare.py --verify
python -B prepare.py --packet A --destination /tmp/p4-calibration-a
python -B prepare.py --packet B --destination /tmp/p4-calibration-b
python -B prepare.py --packet C --destination /tmp/p4-calibration-c
```

试答之后统一了九处 traceback 的脚本路径。校验确认只有路径字符串变化，所有输出语义、任务、代码和历史材料保持一致。冻结清单保留试答时的证据哈希和最终版哈希。候选分发顺序预留每组两次独立会话，实际派发记录为空。
