# E003 · P4 Job 生命周期交接对照

作者确认用公开 Kubernetes 记录作为 P4 的第二案例，并授权材料复核冻结后派发。这个案例横跨 Job 控制器、API 状态校验与使用 Job 状态的下游流程。#16 继续保留为评分校准，其试答独立于本次正式统计。 [冻结的校准记录](../p4-calibration/README.md)

**P4 已收口。** 六份答卷及原始评分以 `14d0772` 为归档基线。阶段复盘保留 V10 的评阅分歧、对照的结论范围及成本缺口。 [E003 阶段复盘](../retrospective.md)

## 案例选择

| 规则 | 本案证据 |
| --- | --- |
| 失效机制与批量校验器不同 | Job 的提前条件、终态发布、API 状态校验和下游等待是不同环节。 |
| 历史信息分散并可定位版本 | #123775 保留现场状态和另一次时间轴。#125510 合并了终态延后。#132144 给出零完成数暂停 Job 的回归、独立复现和后续修复证据。固定提交对应上游 v1.30.0、v1.31.9、v1.32.0、v1.32.7。 |
| 未知来自真实记录的边界 | #133903 有 EKS 状态快照和报告人的关单归因，原议题和评论缺同一 UID 的 API 更新、策略和资源归还的时序。保留关单说明及已知复现，允许有依据的保留判断。 |

本仓库的 #13 需要以历史测试修复和后续临时变异重放来组织，当前没有一次可指认的历史变异 CI 事故。#6a 的修复保留为实验补丁。异步设备线索暂缺可复核运行记录。这个公开案例同时具备真实版本变化和现场证据边界。 [原始材料与固定引用](sources.md)

## 材料与评阅

三组各收到相同的 [任务](task.md) 与 [共同材料](sources.md)。B 的线性摘要和 C 的文本关系图由同一份历史主张清单生成，逐项保留版本、前提、状态及证据。额外材料只处理 H1–H4。两份附加材料以同一文件名 `history-note.md` 发放，评分参考与其他组材料不入包。 [历史主张](claims.json) · [线性摘要](summary.md) · [文本图谱](graph.md)

独立复核者把参考判据与公开议题、合并变更和固定源码核对。共同材料随后按来源分开陈列，T2 保留报告人的关闭说明，评阅者判断的缺项留在参考表。两份附加材料按最终主张清单生成，分发前逐行反解核对十条主张并封存哈希。另一个独立会话复核了同一冻结版本的等义性和答案隔离，反馈在首批 A、C 启动后、B 补发前到达，期间材料字节一致。 [冻结与分配](freeze.json)

按两批分发，每批各有 A、B、C 一场独立会话。会话用同一默认模型配置和任务，从不同目录只读规定范围的材料。访问限制依赖会话遵循约定，实际读取量和 token 用量采用可取得的记录。每份答卷按独立会话报告，分发时间随槽位释放而错开，完成耗时只作描述性记录。

评阅分别记录知识恢复的六项和有效性判断的十项，同时保存无依据断言和肯定、否定、证据不足的细分结论。两轴分开呈现，逐项展示，正式授权独立于会话提出的修订。评阅参考对作者归因、证据不足与真正的版本变化分别处理。 [评分参考](reference.md)

比较 B 与 A 可观察组织材料的增量，比较 C 与 B 可观察两份等义文本呈现之间的差异。结果限于本案例、所给资料和小样本。各组收到的材料含原始记录的事实摘录与固定源码定位。发行商运行轨迹和资源账本未在本地复现。文本图谱对照未施加图检索工具。

从本文件所在目录可校验两份历史材料及重建指定组的分发包。目标目录应为空路径。

```sh
python3 -B prepare.py --verify
python3 -B prepare.py --packet A --destination /tmp/p4-job-a
```

## 正式结果

三组各收到两份独立答卷。首批 B 首次派发因并发槽限制未创建会话，后续按原编号和封存包补发。两批后续会话随槽位释放启动，六份交付材料的哈希均匹配。两位独立评阅者分别看一批匿名答卷，分组表留在组织者侧，答卷引用仍可能透露材料条件。 [分发、答卷和逐项评阅](submissions.json)

| 编号 | 条件 | 知识恢复满足 | 有效性满足 | 有效性部分满足 | 派发标记至落盘 |
| --- | --- | ---: | ---: | ---: | ---: |

六份答卷都恢复了全部历史事实判据，并将现场具体根因与实际资源归还判为证据不足。它们均能区分 #132144 独立复现中有日志支持的 `startTime` 校验拒绝，与 #133903 中公开快照和报告人归因支持的有限结论。独立评阅未标出无依据的实质断言。

唯一的部分满足项是 V10。C 两份答卷均把修订标为候选，列出现场证据的核验责任方，欠缺交接条目的采纳责任方。两位评阅者对这两份答卷的 V10 初评分不同。组织者按冻结任务中明确确认方的要求对齐给分，将 788 的 V10 从满足改为部分满足，同时保留两份初评分和对齐理由。 [冻结判据](reference.md) · [初评与复核](submissions.json)

A、B 两组在两轴均达到满分。本案未观察到额外整理或文本图谱带来增量。C 的观察差异集中在修订责任说明，样本规模和单案例范围不足以把它归因于表示形式。三组均能在自然证据缺口下限定结论，这是本次观察到的能力。

可用材料为 A 7,893 字符、B 9,243 字符、C 9,489 字符。派发时间包含调度和环境因素。任务记录了会话自述的工具和查阅文件，实际读取量、token 用量和人工整理净工时缺少测量，无法比较净效率。 [输入字符数](freeze.json) · [运行计量](submissions.json)
