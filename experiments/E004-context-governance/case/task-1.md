# T1 · 按仓交付

出库通知当前由 `export(events)` 全量交付，接收程序按仓维护活动出库记录。现在需要减少其他仓的发货通知。为 `dispatch.py` 增加 `export(events, *, depot: str | None = None)`。

- 指定仓时，仅该仓的发货通知需要投递。同一批事件经这次交付后，现有接收端 `active_movements(depot, delivered)` 应得到与全量交付后相同的活动记录。
- 消费者会连续接收多批，某次撤销可以对应更早一批的发货。
- 未指定仓时保留原有投递行为。保留已有事件顺序、事件内容和审计事件过滤。
- 输入为一次性或可重复迭代的有效事件流。序号唯一，可以不连续，输入可无序。当前事件类型为 `ship`（有仓号）、`void`（无仓号）、`note`（审计）。
