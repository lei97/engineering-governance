# T2 · 有检查点的分页

出库交付要接入持续轮询的 w2 消费者。保留完整交付接口 `export`，在 `dispatch.py` 中新增 `page(events, *, after: int, limit: int, depot: str | None = None) -> tuple[list[Event], int]`，依次返回本批可投递事件和消费者下次调用使用的检查点。

- `after` 是已处理的源事件序号。按序号递增扫描更大的事件，一次调用最多扫描 `limit` 条原始事件。
- 延续完整交付的按仓行为、审计过滤、顺序和事件内容。即使一批交付为空，消费者也要能继续处理后面的事件。
- 输入为一次性或可重复迭代的有效事件流。序号唯一，可以不连续，输入可无序。`limit` 是正整数。
