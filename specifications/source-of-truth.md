# 真源规则 v0.1

1. 项目真源可能是用户签署需求、设计决策、设备行为、代码或实验数据，须指定事实所属范围；不能按“文件更新时间较新”选权威。
2. YAML 记录是**索引与明确约束的承载体**，不是所有内容的副本。
3. `origin` 指向具有证据属性的 `source` 记录。`source` 的 `location` 是本实验中的路径/标识文本；验证器不保证远端 URL 可访问或实际证据充分。
4. `relations` 仅声明允许的类型化边；v0.1 检查存在性、类型和自引用，不证明影响范围完整。
5. `accepted` 的转换必须有人的授权记录；v0.1 校验器只核对字段值，**不证明授权真实性**。
6. 若实现与确认的需求冲突，不得自动改写需求来匹配现状；应报告冲突，由授权者裁决。
7. 逆向提取的行为先标注为 `observation`，经核对和确认才能成为正式要求。
