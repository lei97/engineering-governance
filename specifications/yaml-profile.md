# YAML Profile v0.1

用 YAML 1.2.2 的人类可读子集表达项目知识；解析器的实际行为由仓库校验器定义。

## MUST

- UTF-8；一个文件一个顶层 mapping；文件以 `.yaml` 结尾。
- 所有键为字符串，键不能重复；关键字段依 Schema 填写。
- 关键语义放在字段值中，不依赖注释或字段排序。
- ID 大写前缀+数字，如 `REQ-001`；跨文件唯一且引用可解析。
- 多行自然语言优先使用块标量 `|`；写成能被人复述、检查的句子。

## MUST NOT

- 不使用 YAML anchors、aliases、显式 tags、合并键 `<<`、多文档流或复杂映射键。
- 不使用隐式布尔/日期/数字类型作为知识记录字段；v0.1 所有叶子标量均为字符串。
- 不在同一段陈述中混合“已观察事实”和“待验证假设”。
- 不用 `status: accepted` 表示实现通过或已验证。

## SHOULD

- 每个记录表达一个可独立定位的知识单元。
- 需求写出可观察行为，避免“更好”“优化”等无判定标准的词。
- 只增加能提高检索、校验、追溯的字段；不要重复代码或文档正文。

## 限制

Schema 和脚本能发现结构错误、悬空引用等；无法自动证明中文描述无歧义、内容真实、授权有效。这些须在实验中由人审核。
